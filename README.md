# Mimi's Magic Playhouse V6

New in V6:
- 6 themed rooms: Dance Room, Dream Bedroom, Magic Garden, Treat Kitchen, Gem Cave, Art Studio
- Level and XP system
- More mini games: Bubble Pop, Memory Match, Music Mixer, Cookie Catch
- Bigger gem shop with more dresses and more wands
- Some shop items require higher levels as well as gems

Install:
1. Upload all files to your GitHub Pages or web hosting folder.
2. Open the site on iPhone Safari.
3. Add `?v=6.0` to the URL once to refresh the cached files.

Notes:
- No ads, accounts or uploads.
- Voice clips stay local in the browser memory.
- Save data is stored locally on the device.
